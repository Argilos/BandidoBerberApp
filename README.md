# Bandido - Barbershop Booking Platform

Bandido is a modern barbershop booking platform built with React, Vite, and Firebase. It provides a seamless experience for clients to book appointments and a comprehensive admin panel for barbers to manage their schedule, services, and approvals.

## Key Features

- **User Authentication**: Secure login and registration using Firebase Auth.
- **Booking Flow**: Intuitive appointment scheduling interface for clients.
- **Admin Dashboard**: Dedicated admin suite to manage bookings, approve appointments, and configure services.
- **Service Management**: Real-time management of barber services and availability.
- **Responsive Design**: Beautiful, responsive layout built with Tailwind CSS.

## Tech Stack

- **Frontend**: React, Vite
- **Styling**: Tailwind CSS
- **Backend & Database**: Firebase Authentication, Cloud Firestore
- **Deployment**: Firebase Hosting (Optional)
